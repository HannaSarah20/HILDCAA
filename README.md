# Eventos HILDCAA, oque são?
### Fenômenos geomagnéticos e ionosféricos caracterizados por atividade auroral contínua, de alta intensidade e longa duração, associados a correntes de vento solar de alta velocidade.
Causas: São impulsionados por trens de ondas de Alfvén interplanetárias que interagem com o campo magnético da Terra por meio de reconexão magnética intermitente
O estudo se baseia na ideia de calcular os eventos com uma nova análise, de duração que normalmente deve durar no minimo dois dias e devem obrigatoriaente ocorrer fora de tempestades solares, os eventos HILDCAA* implicam em diminuir o tempo para qe novos eventos surjam para analises mais detalhadas com relação a esses eventos.
### Objetivo do projeto:
Calcular os eventos HILDCAA e HILDCAA*, para os ciclos solares 23 e 24, fazer comparações e analizar os eventos. Os dados brutos para análise foram tirados do site "https://omniweb.gsfc.nasa.gov".
